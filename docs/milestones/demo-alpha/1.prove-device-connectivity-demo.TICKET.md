# Prove device connectivity (ngrok tunnels, 3 devices)

**Type:** Spike (not the real demo build), infra prerequisite for `SPEC.md`'s Phase 1 build.

**Goal:** Confirm a physical iPhone, Android phone, and browser can all reach local Supabase (Docker) via ngrok tunnels, using a single-screen raw-JSON-dump app.

## Decisions
- No RLS/grant changes. A PostgREST "permission denied" response **is** success, proof the request reached Kong → PostgREST → Postgres.
- Local native builds via USB (`expo run:ios/android --device`), no EAS.
- ngrok tunnels only (LAN IP blocked by AP isolation), two separate tunnels: Expo `--tunnel` (Metro/JS bundle) and `ngrok http 54321` (Supabase API).

## Tasks
- [ ] `src/lib/supabase.ts`: typed client from `EXPO_PUBLIC_SUPABASE_URL`/`_ANON_KEY`, throw if unset.
- [ ] `src/app/index.tsx`: on mount, `supabase.from('products').select('*')`, render `data ?? error` as JSON.
- [ ] `.env.app.local.example`: template for ngrok URL + anon key. (User fills real `.env.app.local` manually, CLAUDE.md blocks Claude from touching `.env*`.)
- [ ] `npx expo install expo-dev-client`; let `expo run:*` prompt for bundle IDs on first run.
- [ ] Stand up ngrok: `ngrok http 54321` (Supabase API) + `npx expo start --dev-client --tunnel` (Metro).
- [ ] Build/install on device via USB, load JS via the Expo tunnel URL.

## Verification
- `curl` and phone browser hitting the ngrok URL → `permission denied` / `No API key found` JSON.
- App on web, Android, iOS all show the same JSON regardless of network.
- `pnpm lint` clean.
